Como a arquitetura de borda única simplifica grids CSS

A maior parte dos bugs visuais em listas e grids vem de bordas duplicadas: dois elementos vizinhos desenhando a mesma linha, cada um na sua metade. O sistema de borda única resolve isso atribuindo a responsabilidade da borda a exatamente uma célula.

A regra

Toda .g-row abre o grid com border-left; toda .g-cell fecha com border-right e border-bottom. Nenhuma outra combinação é permitida. 

.g-cell {
  border-right: 1px solid var(--color-border);
  border-bottom: 1px solid var(--color-border);
}

Uma célula é uma folha visual, não um contêiner. Wrappers de layout nunca recebem borda própria.

Na prática, isso significa decompor qualquer bloco em uma lista simples:

  • Cada elemento independente vira uma célula.
  • Elementos lado a lado compartilham uma linha.
  • Linhas empilhadas formam uma coluna sem repetir bordas.

O resultado é previsível em qualquer densidade de conteúdo, sem precisar de box-shadow ou gradientes para simular profundidade — ver a documentação completa.
